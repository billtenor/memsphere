# 极简内容视图（兼容示例）

这套样式现已是系统默认样式，无需安装或选择扩展包即可生效。本目录保留为兼容示例，供旧版本安装或扩展包开发参考。它保留系统记忆与运行页面的全部功能，同时：

- 通过 `mem-content-*` 共享展示原语统一 Memory Procedure 与 Run；Run 只追加运行状态、评审绑定和步骤产出物，不再维护第二套流程样式；
- 移除内容卡片的实线边框，以留白和浅色背景表达层级；
- 产物默认只显示名称，类型、格式和最终产物标记在悬停或键盘聚焦时显示；
- 将评审从产物信息中分离，默认只显示评审人数量，具体评审人在悬停或键盘聚焦时显示。

在尚未内置这套默认样式的旧版本中，可在“设置 → 界面与主题 → 界面扩展包安装”中安装本目录，然后在“全局样式”中选择“borderless-content”。

也可在“公共组件 / 内容画布、流程展示、折叠字段”中分别选择本包的 `document`、`flow`、`disclosure`，或使用“一键应用全部”。组件选择同时作用于 Memory 和 Run。取消组件选择会恢复公共默认实现；细部极简样式由上述全局样式提供。公共输入契约见 [Slot Catalog](../../../docs/view-slots.md)。
