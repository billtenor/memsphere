# Graph Run 支持回溯重走：需求概述

## 需求

### 背景与目标

Graph Run 推进到后续阶段后，需求、技术方案或其他已接纳的上游成果可能发生变化。用户需要在同一个 Run 中回到指定阶段，修订成果并重新经过所需评审，然后继续后续工作。

当前 graph 执行器拒绝重新进入已 done 的 Step；冻结流程未声明回边时，没有正式入口完成上述操作。本次 Runner 身份与异步等待迭代即遇到该问题：实现验收期间调整了技术方案，需要重新进行方案评审，再进入实现验收和产品验收。

回溯应成为 graph Run 的通用运行能力，适用于不同 Procedure，不要求每份流程预先编写返工回边，也不要求为了返工另建替代 Run。它与流程作者预先定义的正常业务循环分别表达。

### 当前迭代范围

1. **同Run回溯。** 运行中的graph Run可显式选择需要重做的已接纳Step，返回该阶段修订、评审，再按原流程依赖继续。Run ID不变，沿用冻结的Procedure及权限规则；不通过修改状态文件或改写来源Memory实现回溯。
2. **明确目标与影响。** 循环中同一Action可能有多个Step，必须定位具体实例。执行前可查看目标、实际受影响的下游、相关评审及后台任务；操作说明回溯原因。具体CLI名称和交互在技术方案中确定。
3. **保留历史。** 旧Step、Artifact、依赖、评审轮次、票和意见均保留。系统形成可追溯的新执行与修订关系，明确区分当前有效执行链和历史分支；具体模型与状态变更须在技术方案中说明。
4. **重新通过门禁。** 新版上游成果必须按该阶段配置重新评审。受影响的下游不能继续用旧版“通过”结论满足当前链路门禁；方案重审后，还须检查实现是否符合新方案并完成受影响验证，再进入实现与产品验收。
5. **按依赖处理下游。** 正确处理顺序、并行分支、条件、循环、join和collect。实际不依赖被修订成果的分支保持有效；受影响分支重新生产或经明确的重新核验步骤形成新成果，不静默复用旧通过状态。历史collect结果不变，当前链路的聚合依据重新建立。
6. **隔离过期执行。** 对受影响且仍进行中的Reviewer、异步等待、迟到投票、通知和生产提交给出一致处理规则，旧执行不得推进新链路或覆盖会话当前绑定。可继续保留历史诊断，不能把基础设施超时等同于已完成评审。
7. **可恢复与可观察。** 并发推进、回溯与重试不得生成互相冲突的当前链路。中断恢复及同一次回溯请求重试不应重复创建返工链；新的再次回溯应可明确区分。status/show、CLI继续提示和View应能识别当前阶段、历史关系及后续入口。
8. **适用边界。** 至少支持升级后新建的graph Run；既有运行中graph Run（包括本次实际受阻Run）的支持、模型升级及兼容限制必须在方案中明确，不得默认“只能重新开Run”完成交付。

### 非目标与边界

- 不撤销Git提交、文件改动、已发消息、部署或其他外部副作用；需要补偿时显式列出，由相关业务动作处理。
- 不修改已冻结的Procedure定义，不增加任意跳步或绕过Human/Reviewer门禁的入口。
- 本次不要求flow或自由探索新增回溯机制，也不默认重新打开done/abandoned Run。
- 不要求删除历史产物、克隆整个Project或重新执行不受影响的所有分支。

## 验收标准

- 在“方案已通过、实现验收尚未完成”的同一graph Run中，能够回溯方案阶段，重新收集研发、测试、架构及已配置Human的评审；通过后重新推进实现核验、实现验收、产品验收，不创建替代Run或借用旧票放行。
- 旧方案、实现、票和依赖完整可读；当前链路明确采用新方案，历史下游不被自动改写。
- 覆盖并行分支不误伤、循环目标实例不歧义、join不混合新旧信号、collect不带入已失效分支。
- 回溯时存在运行中的Reviewer或后台等待，旧回调/通知不能使新链路通过或切换会话上下文。
- 覆盖重复请求、并发report/vote/advance、执行中断与恢复，失败不产生可被错误放行的半完成状态。
- 明确验证新建及既有运行中graph Run的支持范围；需要升级时提供受控路径。实际运行的继续命令和View展示与当前有效链一致。

## 技术与测试方案

尚未设计。需重点调查Graph运行时、Step/Artifact/Review模型、有效依赖与完成信号、join/collect、会话绑定、ACP和daemon任务的失效边界，再提交各Reviewer评审。不得把本概述当作模型或状态机方案已获批准。

测试以真实graph Run的“方案变更→回溯重审→重新验收”闭环为主，补并行、循环、汇合、聚合、迟到事件和中断恢复场景，并验证旧历史不变。
