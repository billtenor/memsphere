# 需求契约第二轮修订摘要

依据 Human 第一轮两条正式修改意见，将原先泛化的行为验收改为两个必须实际执行的验收。

1. 发起子 Agent 完成一次有一定复杂度的真实流程记忆撰写，任务覆盖多步骤、实质分支与循环、不同产物、全局与局部要求；逐项核对字段职责、重复、作用域与业务要求保留。
2. Runner 先撰写问题样本并记录全部考点，再发起独立子 Agent review，不提供问题答案；逐项核对全部考点命中、漏检及误报。
3. 两项都通过才认可有效，保留原始输入输出、规范版本、配置与所有尝试记录；语法和仓库回归不能替代这两项验收。

本轮只修订需求契约，未执行后续方案、实现或验收步骤。
