# 依赖图展示与交互设计

使用现有Run模块及浮窗，不新增模块或图编辑器。默认展示根统一来自Snapshot.outputArtifactIds（推导成果）。

## 展示范围

| 视图 | Artifact范围 | External范围 |
| --- | --- | --- |
| 运行中默认图 | outputArtifactIds及其实际依赖闭包 | 可见产物引用的资料，以及从未被任何完整产物引用的新资料 |
| 某个历史版本 | 沿用该版本的实际上下游历史投影 | 只取该投影中可见产物实际引用的资料 |
| 交付视图 | 已完成Run按固定图与人工增删推导的outputArtifactIds及其依赖闭包 | 只取交付闭包引用的资料 |
| outputs为空 | 无Artifact；不回退到所有产物族或所有草稿 | 运行中仍展示从未被完整产物引用的新资料；已结束时无独立资料 |
| 只有External、尚无产物 | 无Artifact | 运行中正常展示未引用资料节点 |

默认图不再从“每个产物族的最新版”求并集，也不把所有草稿、未完成提交拼回图中。隐藏范围由成果根决定，不能以current／history标签代替。outputs为空且无资料时显示“暂无成果”；被手动移出的Artifact若仍被其他成果依赖，应继续显示。

进入页面和刷新直接展示当前成果图；无需在历史菜单重新选最新版才能看到主干。历史选择仍只切换该版本的上下游图，点击节点才打开浮窗，浮窗内翻页保持打开并同步后台图。退出历史时回到当前outputArtifactIds的默认图，运行中按钮文案改为“回到当前成果”，完成后为“回到交付视图”。不增加“聚焦依赖”按钮或持久化前端选择。

只供已收起历史产物使用的资料随历史收起；已被隐藏产物引用的资料不伪装成新资料。未被引用的新资料作为独立节点，不造依赖边。引用状态从dependencies计算，不另存used或引用计数。

## 节点和详情

External使用现有Badge标识“外部资料”，主体为source简短预览；不新增name、title或tags。ID放详情，不显示在图节点上。同一External可供多个产物引用，节点只出现一次，真实边方向为External→依赖它的Artifact，身份按kind+id区分。

点击External沿用当前宽浮窗，单栏显示完整来源和内容，不显示Review栏或版本控件。文本及Markdown沿用现有渲染，非文本可下载；contentRef仍通过内容服务读取并核对SHA-256。网页不套用CLI的200 chars截断。

Artifact的名称、Badge标签、历史选择、左侧内容／右侧Review及浮窗内上一版／下一版保持原行为。切换历史只切依赖图，点击节点才打开浮窗；浮窗内翻页保持打开并同步后台图。查看External不自动改变历史选择。

## 画布平移

| 操作 | 行为 |
| --- | --- |
| 空白处或边上左键拖动 | 手抓式横纵平移整图 |
| 松开、取消、失焦或失去指针捕获 | 立即结束拖拽 |
| 节点、历史菜单、按钮、选择框 | 保留原有点击，不从这些控件开始画布拖拽 |
| 起拖后经过节点或移出画布 | 持续至释放，不误开浮窗，不留下拖拽状态 |
| 滚轮、触控板、滚动条 | 保留原有滚动 |

画布在页面可用区域内形成内部滚动范围，复用scrollLeft/scrollTop，不让大图撑高页面而失去纵向拖拽。Pointer捕获及事件在视图销毁时清理，浮窗文字仍可选择。小位移阈值属于实现细节，不新增配置。没有缩放、无限画布或节点布局编辑。

## 边高亮

悬停边同时高亮该边及全部直接端点，复用现有视觉。采用略宽的透明命中区域，不要求用户精确指向细线。移出只移除这次边悬停，保留仍有效的节点选中、焦点及悬停。不扩展到整条传递依赖链，不增加边点击菜单。

实现和验证覆盖：成果根默认投影、手动移出、空集合不回退、修订与历史返回、仅资料、共享输入、历史独占资料、长source、完整内容、桌面与窄屏、双向拖拽、移出释放、取消／失焦、节点与版本点击、重渲染及监听清理。具体代码文件与测试组织见实施与验证方案。
