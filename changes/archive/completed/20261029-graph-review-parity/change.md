## 浮窗渐进加载优化
Flow/Graph 公共评审只返回所选轮次的完整意见和所选材料正文，其他轮次、上游材料先返回元数据，切换时加载。唯一 Human 在同一响应中确定身份，多 Human 保留显式选择。Flow 直接打开评审跳过隐藏背景 Run 的详情加载。Graph 点击先展示可关闭的加载浮窗，正文与评审并行读取；评审只读取所属 Step 及必要输入，并复用会随模型操作重新校验的 View Store 服务。

本机真实浏览器采样：Graph 浮窗约51ms出现、正文约236ms、评审约245ms就绪，评审请求约83ms/52KB（优化前约609ms/139KB）。Flow 直接评审约274ms就绪（此前约1358ms），评审响应约76KB（此前约200KB）。结果为本机采样，不代表所有环境的保证。新增 API 轻量响应、身份选择、定向 Step 读取和暂停评审响应时正文仍可见的回归覆盖。
