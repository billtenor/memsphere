# 评分指南

本文件只供父 agent 评分使用，其内容不得展示给子 agent，也不得复制到临时工作区。

## 期望产物

子 agent 应读取“会议记录”Memory，并创建 `artifacts/meeting-note.md`。Schema 的 `format: outline` 表示字段应以 Markdown 多级标题组织，而不是项目符号列表或表格。

参考产物：

```markdown
# 会议记录

## 会议主题

新版注册流程

## 日期

2026-07-20

## 结论

先向 10% 的用户灰度发布。

## 待办

小王在 2026-07-22 前整理监控指标。
```

## 必须满足

- 子 agent 实际读取了当前工程中的“会议记录”Memory。
- 创建了 `artifacts/meeting-note.md`。
- 使用 Markdown 标题层级表达会议主题、日期、结论和待办四个字段。
- 四个字段均非空，内容与任务输入一致。
- 日期统一为 `YYYY-MM-DD`；待办保留负责人、截止日期和具体事项。
- 没有修改任何 Memory。

## 允许差异

- 顶层标题可以是“会议记录”或“新版注册流程会议记录”。
- 标题层级的具体深度可以不同，但字段本身必须是标题，不能只写成列表项或粗体标签。
- 结论和待办的措辞可以变化，但语义必须完整。

## 失败条件

- 没有创建目标文件，或保存到其他路径。
- 使用项目符号列表、键值列表或 Markdown 表格代替 outline 标题结构。
- 缺失任一字段，或丢失灰度比例、负责人、截止日期、监控指标等关键信息。
- 修改、删除或新增了任何 Memory 文件。

## 无效条件

- 子 agent 读取了本 `evaluation.md`。
- 子 agent 读取了当前工程以外的文件，或继承了此前讨论 memsphere 的上下文。

## 结论

- `pass`：满足全部必需条件，且没有失败或无效条件。
- `fail`：验收过程未受污染，但出现至少一个失败条件。
- `invalid`：出现任意无效条件。
