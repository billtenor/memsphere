# 评分指南

本文件只供父 agent 评分使用，其内容不得展示给子 agent，也不得复制到临时工作区。

## 期望行为

子 agent 应发现并读取“发布记录”Schema，根据 object + Markdown `layout: outline` 和 `fields` 创建 `artifacts/release-record.md`。

参考产物：

```markdown
# 发布记录

## 版本

v2.4.0

## 发布日期

2026-07-18

## 变更内容

- 新增批量退款功能。
- 修复重复扣款提示错误。

## 发布结果

成功
```

## 必须满足

- 子 agent 实际读取了当前工程中的“发布记录”Schema。
- 创建了 `artifacts/release-record.md`。
- 版本、发布日期、变更内容和发布结果均使用 Markdown 标题表达且内容非空。
- 日期为 `2026-07-18`，结果为“成功”。
- 两项变更均被保留。
- 没有修改任何 Memory。

## 允许差异

- 顶层标题和字段标题的具体层级可以变化，但四个字段必须是标题。
- 变更内容可以使用段落或项目符号。
- 措辞可以调整，但不得改变事实。

## 失败条件

- 没有创建目标文件，或保存到其他路径。
- 使用键值列表、项目符号或表格代替字段标题。
- 缺少任一字段或任一项变更。
- 发布日期格式错误，或发布结果不是“成功”。
- 修改、删除或新增了任何 Memory 文件。

## 无效条件

- 子 agent 读取了本 `evaluation.md`。
- 子 agent 读取了当前工程以外的文件，或继承了此前讨论 memsphere 的上下文。

## 结论

- `pass`：满足全部必需条件，且没有失败或无效条件。
- `fail`：验收过程未受污染，但出现至少一个失败条件。
- `invalid`：出现任意无效条件。
