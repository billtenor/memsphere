# 评分指南

本文件只供父 agent 评分使用，其内容不得展示给子 agent，也不得复制到临时工作区。

## 期望行为

子 agent 应读取“设备盘点表”Schema，根据 array + Markdown `layout: table` 及其 item object 创建 `artifacts/device-inventory.md`。

参考产物：

```markdown
| 资产编号 | 设备 | 归属人 | 状态 | 位置 |
| --- | --- | --- | --- | --- |
| MBP-017 | MacBook Pro | 陈晨 | 使用中 | 上海 A-12 |
| DSP-204 | 显示器 | 未分配 | 闲置 | 上海库房 |
| TP-088 | ThinkPad | 王宁 | 维修中 | 北京维修点 |
```

## 必须满足

- 子 agent 实际读取了当前工程中的“设备盘点表”Schema。
- 创建了 `artifacts/device-inventory.md`。
- 使用合法 Markdown 表格，列为资产编号、设备、归属人、状态和位置。
- 三台设备各占一行，信息与任务输入正确对应。
- DSP-204 的归属明确表达为“未分配”“无人领用”或等价含义。
- 三个状态分别为“使用中”“闲置”和“维修中”。
- 没有修改任何 Memory。

## 允许差异

- 可以在表格前增加简短标题。
- 未分配归属人的表达可以不同，但不能虚构姓名。
- 列顺序应遵循 Schema；单元格措辞可以作不改变事实的调整。

## 失败条件

- 没有创建目标文件，或保存到其他路径。
- 使用标题大纲、项目符号或键值列表代替 Markdown 表格。
- 缺少任一列或任一设备，或把不同设备的信息混在同一行。
- 使用 Schema 不允许的状态值。
- 修改、删除或新增了任何 Memory 文件。

## 无效条件

- 子 agent 读取了本 `evaluation.md`。
- 子 agent 读取了当前工程以外的文件，或继承了此前讨论 memsphere 的上下文。

## 结论

- `pass`：满足全部必需条件，且没有失败或无效条件。
- `fail`：验收过程未受污染，但出现至少一个失败条件。
- `invalid`：出现任意无效条件。
