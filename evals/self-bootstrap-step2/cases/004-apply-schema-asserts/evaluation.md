# 评分指南

本文件只供父 agent 评分使用，其内容不得展示给子 agent，也不得复制到临时工作区。

## 期望行为

子 agent 应读取“上线检查记录”Schema，创建 `artifacts/release-check.md`，并在实现 outline 结构的同时满足 Schema 自身的 `asserts`。

参考产物：

```markdown
# 上线检查记录

## 版本

v3.2.1

## 数据库迁移检查

通过

## 接口冒烟检查

通过

## 回滚版本

v3.1.8
```

## 必须满足

- 子 agent 实际读取了当前工程中的“上线检查记录”Schema。
- 创建了 `artifacts/release-check.md`。
- 四个字段均使用 Markdown 标题表达且内容非空。
- 待上线版本为 `v3.2.1`，回滚版本为 `v3.1.8`。
- 两项检查均严格填写为“通过”。
- 没有修改任何 Memory。

## 允许差异

- 顶层标题和字段标题的具体层级可以变化。
- 可以补充不改变检查结论的说明，但不能替换 Schema 规定的字段值。

## 失败条件

- 没有创建目标文件，或保存到其他路径。
- 版本号缺少 `v` 前缀，或版本事实发生变化。
- 使用“已完成”“正常”“pass”等值代替“通过”。
- 缺少任一字段，或未使用 outline 标题结构。
- 修改、删除或新增了任何 Memory 文件。

## 无效条件

- 子 agent 读取了本 `evaluation.md`。
- 子 agent 读取了当前工程以外的文件，或继承了此前讨论 memsphere 的上下文。

## 结论

- `pass`：满足全部必需条件，且没有失败或无效条件。
- `fail`：验收过程未受污染，但出现至少一个失败条件。
- `invalid`：出现任意无效条件。
