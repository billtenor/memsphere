# 评分指南

本文件只供父 agent 评分使用，其内容不得展示给子 agent，也不得复制到临时工作区。

## 期望行为

子 agent 应在“单次客户反馈记录”和“客户反馈汇总表”之间选择后者，读取完整 Schema，并创建 `artifacts/customer-feedback-summary.md`。

参考产物：

```markdown
| 日期 | 渠道 | 反馈内容 | 处理状态 |
| --- | --- | --- | --- |
| 2026-07-10 | App 内 | 搜索速度慢 | 正在排查 |
| 2026-07-11 | 电话 | 发票无法下载 | 已修复 |
| 2026-07-12 | 邮件 | 希望增加深色模式 | 待评估 |
```

## 必须满足

- 子 agent 实际读取了当前工程中的“客户反馈汇总表”Schema。
- 创建了 `artifacts/customer-feedback-summary.md`，没有创建单次反馈记录实例。
- 使用 Markdown 表格，包含日期、渠道、反馈内容和处理状态四列。
- 三条反馈各占一行，日期统一为 2026 年的 `YYYY-MM-DD` 格式。
- 每条反馈的渠道、内容和状态与任务输入正确对应。
- 没有修改任何 Memory。

## 允许差异

- 可以同时读取两份候选 Schema 后再作选择。
- 可以在表格前增加简短标题。
- “App 内”“正在排查”“已修复”等措辞可以使用不改变语义的等价表达。

## 失败条件

- 选择“单次客户反馈记录”并创建一个或多个 outline 文件。
- 没有读取目标 Schema，仅根据任务文字自行决定结构。
- 没有创建目标文件，或保存到其他路径。
- 使用标题大纲、项目符号或键值列表代替 Markdown 表格。
- 缺少任一反馈或任一字段，或把不同反馈的信息错误组合。
- 修改、删除或新增了任何 Memory 文件。

## 无效条件

- 子 agent 读取了本 `evaluation.md`。
- 子 agent 读取了当前工程以外的文件，或继承了此前讨论 memsphere 的上下文。

## 结论

- `pass`：满足全部必需条件，且没有失败或无效条件。
- `fail`：验收过程未受污染，但出现至少一个失败条件。
- `invalid`：出现任意无效条件。
