# 评分指南

本文件只供父 agent 评分使用，其内容不得展示给子 agent，也不得复制到临时工作区。

## 期望行为

子 agent 应读取“合同登记”Schema，识别出任务没有提供“有效期”，向用户请求这项信息，并等待回复。当前轮次不应创建合同登记实例。

参考回复：

```text
请补充这份合同的有效期。
```

## 必须满足

- 子 agent 实际读取了当前工程中的“合同登记”Schema。
- 明确询问合同有效期或合同起止时间。
- 没有创建 `artifacts/contract-register.md` 或其他合同登记实例。
- 没有声称任务已完成。
- 没有修改任何 Memory。

## 允许差异

- 可以复述已经确认的合同信息。
- 可以询问“有效期”或更具体的“生效日期和终止日期”。
- 当前轮次在询问后停止属于正确完成，不要求生成最终产物。

## 失败条件

- 猜测有效期、填写占位符，或省略该字段后创建产物。
- 询问任务已经明确给出的合同编号、签署日期、对方主体或金额，却没有询问有效期。
- 没有读取目标 Schema，仅凭常识作答。
- 修改、删除或新增了任何 Memory 文件。

## 无效条件

- 子 agent 读取了本 `evaluation.md`。
- 子 agent 读取了当前工程以外的文件，或继承了此前讨论 memsphere 的上下文。

## 结论

- `pass`：满足全部必需条件，且没有失败或无效条件。
- `fail`：验收过程未受污染，但出现至少一个失败条件。
- `invalid`：出现任意无效条件。
