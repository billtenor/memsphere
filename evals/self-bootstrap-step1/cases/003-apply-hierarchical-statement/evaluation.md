# 评分指南

本文件只供父 Agent 评分使用，其内容不得展示给被测 Agent，也不得复制到临时工作区。

## 验收目标

检查被测 Agent 能否读取树状的“代码变更说明规则”，应用根节点、相关分支和深层子节点中的全部规则，同时不把无关兄弟分支的规则强加给当前任务。

## 期望行为

Agent 应创建 `artifacts/change-summary.md`，说明变更单 `CHG-2841`、订单服务、字段迁移、旧接口兼容性、迁移预演结果，以及恢复旧字段并回切 2.6.3 的回滚方式。当前任务不涉及前端变更，不需要浏览器或视觉回归信息。

## 必须满足

- 被测 Agent 实际读取了当前工程中的“代码变更说明规则”Memory。
- 创建了 `artifacts/change-summary.md`。
- 产物包含变更单号 `CHG-2841`。
- 产物说明受影响的是订单服务，并说明旧接口仍兼容整数输入。
- 产物说明 `orders.status` 从整数迁移为字符串枚举，迁移脚本已经通过预演。
- 产物说明回滚时恢复旧字段并回切 2.6.3。
- 没有因为前端分支规则而阻塞任务或请求无关信息。
- 没有修改、删除或新增任何 Memory。

## 允许差异

- 标题、段落、列表和具体措辞可以自由组织。
- 可以主动说明“本次不涉及前端”，但不是必需。
- 可以补充风险提示或观察建议，只要不改变题目提供的事实。
- 可以把“字符串枚举”写成等义的技术表述。

## 失败条件

- 遗漏根节点、后端分支或数据库子节点中的任意适用规则。
- 要求用户补充浏览器、截图或视觉回归信息后才继续。
- 因为缺少前端信息而拒绝或暂停创建产物。
- 编造具体枚举值、迁移时间或其他未提供事实。
- 没有创建目标文件，或保存到其他路径。
- 修改、删除或新增任何 Memory 文件。

## 无效条件

- 被测 Agent 读取了本 `evaluation.md`。
- 被测 Agent 读取了当前工程以外的文件，或继承了此前讨论 memsphere 的上下文。

## 结论

- `pass`：满足全部必须条件，且没有失败或无效条件。
- `fail`：验收过程未受污染，但出现至少一个失败条件。
- `invalid`：出现任意无效条件。
