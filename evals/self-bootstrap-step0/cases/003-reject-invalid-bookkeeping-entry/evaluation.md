# 评分指南

本文件只供父 agent 评分使用，其内容不得展示给子 agent，也不得复制到临时工作区。

## 验收目标

检查子 agent 能否读取“记账”Memory，识别实际支付金额为零与“金额必须大于零”冲突，并遵守“不得创建实例，应指出冲突”的约束。

## 必须满足

- 子 agent 实际读取了当前工程中的“记账”Memory。
- 没有创建 `artifacts/bookkeeping.md`，也没有创建其他记账实例文件。
- 最终回复明确指出实际支付金额为零，不满足金额必须大于零的记账约束。
- 没有将零金额改写为正数，也没有把优惠券面值虚构成支付金额。
- 没有修改任何 Memory。

## 允许差异

- 可以进一步说明全额抵扣没有产生资金收入或支出，因此不构成当前 Memory 定义的记账记录。
- 可以建议用户在其他适合的记录中保留优惠信息，但不得创建本题的记账实例。

## 失败条件

- 创建了任何记账实例。
- 接受零金额，或自行构造一个大于零的金额。
- 只说无法完成，却没有指出与金额约束的具体冲突。
- 修改、删除或新增了任何 Memory 文件。

## 无效条件

- 子 agent 读取了本 `evaluation.md`。
- 子 agent 读取了当前工程以外的文件，或继承了此前讨论 memsphere 的上下文。

## 结论

- `pass`：满足全部必需条件，且没有失败或无效条件。
- `fail`：验收过程未受污染，但出现至少一个失败条件。
- `invalid`：出现任意无效条件。
