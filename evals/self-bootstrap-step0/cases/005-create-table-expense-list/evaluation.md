# 评分指南

本文件只供父 agent 评分使用，其内容不得展示给子 agent，也不得复制到临时工作区。

## 期望产物

子 agent 应读取“费用清单”Memory，并创建 `artifacts/expense-list.md`。Schema 的 `format: table` 表示每笔支出是一行，日期、内容、金额和分类是 Markdown 表格列。

参考产物：

```markdown
# 费用清单

| 日期 | 内容 | 金额 | 分类 |
| --- | --- | ---: | --- |
| 2026-07-10 | 地铁 | 4 | 交通 |
| 2026-07-11 | 咖啡 | 18 | 餐饮 |
| 2026-07-12 | 打印客户材料 | 12 | 办公 |
```

## 必须满足

- 子 agent 实际读取了当前工程中的“费用清单”Memory。
- 创建了 `artifacts/expense-list.md`。
- 使用合法 Markdown 表格，并且只有日期、内容、金额、分类四列。
- 三笔支出分别占一行，没有合并或遗漏。
- 日期转换为 `YYYY-MM-DD`，金额保持为正数。
- 分类依次表达交通、餐饮和办公语义。
- 没有修改任何 Memory。

## 允许差异

- 金额可以写成 `4`、`4.00` 或带“元”的等价形式。
- 内容可以写成“乘地铁”“购买咖啡”“打印客户材料”等语义等价表达。
- 分类可以使用“办公用品”“办公支出”等与“办公”语义等价的名称。

## 失败条件

- 没有创建目标文件，或保存到其他路径。
- 使用标题大纲或项目符号列表代替 Markdown 表格。
- 表格列不符合 Schema，或任一支出缺失、重复、数值错误。
- 修改、删除或新增了任何 Memory 文件。

## 无效条件

- 子 agent 读取了本 `evaluation.md`。
- 子 agent 读取了当前工程以外的文件，或继承了此前讨论 memsphere 的上下文。

## 结论

- `pass`：满足全部必需条件，且没有失败或无效条件。
- `fail`：验收过程未受污染，但出现至少一个失败条件。
- `invalid`：出现任意无效条件。
